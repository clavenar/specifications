# Clavenar Specifications

This repository holds the public architecture, security model, ABI and protocol
specifications, and architecture decision records.

- [Architecture and vision, draft 0.9](architecture/architecture-and-vision.md)
- [Repository layout, revision 0.1](engineering/repository-layout.md)
- `security/` holds security models and invariants.
- `specifications/` holds normative ABI and protocol documents.
- `adr/` holds numbered architecture decision records.
- `assets/diagrams/`, `templates/`, `tools/`, and `releases/` support document publishing.

The imported architecture draft references four diagram files that were absent
from the source workspace. The document rendering toolchain and license are pending.
